# Materials And Confidence

## Signal Ranking

Use this default order and adjust only with a stated reason:

| Strength | Material | Primary use |
|---|---|---|
| 4 | Past exams, quizzes, assignments, official review sheets | Scope, formats, recurring tasks |
| 3 | Lecture transcripts, teacher notes, detailed class notes | Emphasis, explanation style, caveats |
| 2 | Slides, syllabus, textbook excerpts | Coverage and conceptual structure |
| 1 | Group chats, screenshots, informal recollections | Leads requiring verification |

File names are only a heuristic. Inspect contents before making consequential claims.

## Confidence Labels

Use:

- **Confirmed by course evidence**: directly supported by supplied official or repeated
  high-signal material.
- **Supported inference**: consistent pattern across materials but not explicitly stated.
- **Public background**: sourced from reliable public references, useful for explanation
  but not proof of local exam scope.
- **Speculation**: weak clue or generic expectation. Avoid using it to prioritize large
  amounts of study time.

## Material Quality Assessment

Assess each chapter as:

- `good`: enough explanatory material plus assessment evidence;
- `partial`: usable course coverage but little assessment evidence or missing detail;
- `poor`: fragmentary, unreadable, or absent.

Tell the student exactly what is missing and what conclusions become uncertain.

## Conflict Resolution

When sources disagree:

1. Preserve both claims and their provenance.
2. Prefer newer official course evidence over generic or older material.
3. Prefer direct assessment evidence for format and scope.
4. Do not use a textbook to override an instructor-specific convention without warning.
5. Ask the student to confirm with the teacher when the conflict can affect marks.

## Public Web Research

Default web research may:

- clarify standard concepts;
- verify terminology or formulas;
- locate public course descriptions or official policies;
- find additional lawful practice on the same concept.

It must not:

- upload or quote private source text into a search or external service;
- search for leaked exams or restricted answer keys;
- turn a public explanation into a claim about the student's teacher;
- silently mix web facts with course evidence.

Record title, URL, publisher, retrieval date, intended use, and confidence for each
external source used in a durable artifact.

## Privacy And Copyright

Treat recordings, chats, unpublished exams, student information, and instructor materials
as sensitive. Process locally. Quote only short portions needed for explanation and favor
paraphrase. Warn before redistributing generated artifacts that contain course material.
