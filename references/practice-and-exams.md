# Practice And Exams

## Practice Levels

### L1: Concept Verification

Use short judgment, identification, fill-in, or direct calculation questions. Each
question should isolate one concept. Move on when the student can explain the answer and
maintains about 80% accuracy.

### L2: Integrated Application

Combine concepts, conditions, or representations. Use multi-step calculation, case
analysis, proof outlines, code tracing, or structured essay questions. Require the
student to select the method rather than announcing it.

### L3: Authentic Simulation

Use known past papers when lawful and available. Otherwise reproduce the confirmed exam
format and difficulty without pretending generated questions are real. Include time
limits, marks, and a scoring rubric.

## Guided Problem-Solving

For each teaching problem:

1. Present the question without immediately exposing the solution.
2. Ask the student to restate the target.
3. Extract conditions, constraints, and signal words.
4. Ask for a method and the reason it applies.
5. Guide execution one decision at a time.
6. Check the result using units, bounds, substitution, counterexample, or argument
   consistency.
7. Name the reusable problem type and method.
8. Change one condition and ask for a variation.

## Wrong-Question Records

Record:

- question or stable reference;
- student's answer;
- correct answer or scoring points;
- error category;
- explanation of the cause;
- repair action;
- review status and next review date.

Recommended error categories:

- prerequisite missing;
- concept confusion;
- condition omitted;
- method selection;
- representation or reading error;
- calculation or execution;
- incomplete argument;
- checking failure.

## Question Quality

Generated distractors should reflect plausible misconceptions rather than random wording.
Short-answer prompts should test explanation, not only recall. Essay rubrics should award
specific claims, evidence, structure, and qualification. Calculation rubrics should
preserve method marks where the exam likely does so, while marking that expectation as
inferred unless official evidence exists.

## Mock Exam Review

For every item:

- verify whether a correct answer used valid reasoning;
- diagnose each incorrect answer;
- map the issue back to concepts and error categories;
- assign a focused repair question;
- update the estimated readiness by topic, not only total score.

Never guarantee a final score from one mock exam.

## Final-Night Card

Keep it deliberately small:

- up to five essential formulas or definitions;
- up to three high-risk concept comparisons;
- up to three representative wrong questions;
- exam-format tactics supported by evidence;
- one morning-of reminder.

Do not add new broad topics on the final night unless they unlock a high-value question.
